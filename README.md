# 🧠 MindPlay

> **Play. Think. Grow.**

MindPlay is a fun collection of brain-training games built to challenge your memory, logic, focus, speed, and problem-solving skills.

## 🎮 What You Can Do

- 🧩 Play different brain games
- ⭐ Earn XP and level up
- 🔥 Build your streak
- 🏆 Unlock achievements
- 📊 Track your progress
- ☁️ Save your progress with your account

## ⚡ Built With

**Next.js** · **TypeScript** · **Tailwind CSS** · **Supabase**

## 🚀 Run It

```bash
git clone https://github.com/guddies378/MindPlay.git
cd MindPlay
npm install
npm run dev
Open http://localhost:3000
