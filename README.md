# 🧠 MINDPLAY

> **Think fast. Play smart. 🧠⚡**

A collection of fun, fast-paced brain games built to challenge your **memory, logic, focus, and reflexes**.

### 🎮 THE GAMES

🧠 **Memory Match**  
🔤 **Word Scramble**  
👀 **Odd One Out**  
❌⭕ **Tic-Tac-Toe**  
⚡ **Quick Math**  
🧩 **Riddle Me**

### ⚡ FEATURES

- 🎲 Randomized challenges
- 🏆 Score & progress tracking
- 📅 Daily Challenges
- 📱 Responsive gameplay
- ✨ Clean & playful UI

### 🛠️ BUILT WITH

**Next.js • React • TypeScript • Tailwind CSS**

### 🚀 RUN IT

```bash
git clone https://github.com/guddies378/MindPlay.git

npm install
